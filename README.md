# SURAKSHA
Smart Tourist Safety Monitoring & Incident Response System

A college mini-project prototype built with an npm workspaces monorepo.

## Project structure

- apps/web: React, Vite and TypeScript frontend
- apps/api: Express and TypeScript backend
- packages/shared: shared types, constants and Zod validation schemas
- docs: project documentation

## Current status

Batch 1: root configuration and shared package created.
Frontend and backend will be added in subsequent batches.

## Setup

Requirements: Node.js 20 or newer and Git.

Run:

    npm install
    npm run typecheck

## Security

Never commit environment files containing secrets.
The audit log is a database collection, not a blockchain.
